# Plan y aceptación

1. Base: Next.js, PostgreSQL/Prisma, OAuth GitHub y sesión demo aislada por navegador.
2. Flujo vertical: buscar, consultar detalle, guardar, planificar y ver progreso persistente.
3. MVP: preferencias, checklist, notas, PR, errores, caché y accesibilidad.
4. Calidad: unitarias, integración con dos usuarios, E2E, build y arranque.
5. Ampliaciones: recomendaciones por preferencias, consulta pública de PR y analíticas.
6. Entrega: CI, documentación, despliegue preparado e instrucciones cloud probadas.

Aceptación: búsqueda real sin sustitución de errores por fixtures; demo explícita; aislamiento de usuarios comprobado; migraciones y seed repetibles; sin afirmaciones de OAuth o despliegue no probados.
